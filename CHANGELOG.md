# Changelog

## 1.1.2 — 2026-11-09

First public release.

- Independent MelonLoader overlay for Long Gone Days Build 13316501.
- Ctrl+C default shortcut, configurable in Settings.
- Searchable inventory with immediate quantity editing and an owned-only filter.
- Digit-only numeric fields, including pasted input.
- Character level, base stat, current HP/SP, and maximum HP/SP editing.
- Resource restoration and status/buff clearing.
- Noclip with an always-available off toggle and a safe-tile return control.
- No fullscreen dimming; isolated GUI colors.
- Offline installer with the compiled mod and official MelonLoader 0.7.3 x64 archive.
- Backup-aware updates and mod-only uninstall.
