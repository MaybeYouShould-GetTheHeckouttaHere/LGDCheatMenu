# Controls and features

## Menu

- Ctrl+C: toggle the menu. This is the only default toggle shortcut.
- Esc: close the menu, or cancel shortcut capture.
- Settings > Change shortcut: press a key with optional Ctrl, Alt, or Shift.
- Settings > Reset to Ctrl+C: restore the default.
- Drag the header to move the menu. Settings changes interface size.

## Inventory

Search by item name or ID, choose an item category, or check **Show Only Owned Items**.
Owned includes equipped copies. Counts apply immediately as digits are entered;
there is no Set button. Clearing a field temporarily does nothing, allowing you to
type a replacement. Type 0 to remove all unequipped copies. Counts are limited to
999 and cannot go below the number of equipped copies. A partial replacement
number is an immediate edit too: changing 10 to 25 can temporarily change the count
to 2 while you type.

## Characters

Select a party member. Levels range from 1–999 and can be changed outside battle.
Use Set or Enter for character fields. Base attack, defense, agility, and luck
exclude equipment and temporary bonuses and follow the game's limits (up to 2000).

This game uses **SP/morale**, not a separate MP resource. Current resources and
base maximum HP/SP are separate controls. Maximum overrides remain fixed when
leveling; **Use normal maximums for this level** removes those overrides.

Resource edits apply to the active battle as well as persistent character data.
Battle HP cannot be set below 1, to avoid interrupting death sequences. Restore
HP + SP fills both resources. Clear status effects and buffs removes both helpful
and harmful effects.

## Exploration

Noclip bypasses wall and directional movement restrictions with the normal movement
keys. Map boundaries and occupied NPC cells remain blocked to preserve tile tracking.
Events still trigger. You can disable noclip at any time; an already-started step
finishes after closing the menu. If you are inside a wall, re-enable noclip and move
onto normal ground.

Return to last safe tile works while standing still. Noclip and the safe tile reset
when loading a save or changing locations. Noclip is not saved with your game.
